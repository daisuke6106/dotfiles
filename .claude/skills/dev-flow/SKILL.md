---
name: dev-flow
description: 実装→コードレビュー→テスト実装を各サブエージェントで順に実行する開発フロー
---
以下のタスクを、サブエージェントを順番に呼び出して進めてください。
サブエージェントは会話の文脈を引き継がないため、呼び出す際は仕様・対象ファイル・前ステップの結果を明示して渡すこと。

タスク: $ARGUMENTS

1. **implementer** にタスクを渡して実装させる。
2. **code-reviewer** に変更差分をレビューさせる。
   - Critical / Major の指摘があれば、指摘内容を **implementer** に渡して修正させ、再レビューする。
   - 修正とレビューの繰り返しは最大2回まで。それでも解消しなければ中断してユーザーに判断を仰ぐ。
3. **test-writer** にテストを実装・実行させる。
   - 実装側のバグが報告された場合は **implementer** に修正させ、テストを再実行する。
4. 最後に、変更ファイル・レビュー結果・テスト結果をまとめてユーザーに報告する。
   commit / push は行わない。
